# spara-backend
This is a repository for the backend code for SPARA. The backend is developed using langchain and has RAG architecture. 

To run the main_knowledge_base.py DefaultAzureCredential needs to be installed. Please find the steps for installation, use azure_installation.txt. 

Redis server also needs to be installed. https://redis.io/docs/latest/operate/oss_and_stack/install/install-redis/install-redis-on-windows/ 


After this please install requirements.txt. Please create a new environment for this. 

Please run python main_knowledge_base.py --config main_config.json to run knowledge base.
